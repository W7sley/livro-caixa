    O que é cada cenário?

    Caixinha / conta remunerada costuma render próximo de 100% do CDI, com liquidez diária — é o padrão do Nubank e de várias contas digitais.

    Poupança rende cerca de 6,17% a.a. + TR quando a Selic está acima de 8,5% a.a. (ou 70% da Selic quando está abaixo).

    CDB 110% CDI é um exemplo comum de renda fixa de banco/corretora, geralmente com prazo de resgate.

    As taxas abaixo são editáveis — ajuste para os valores atuais antes de simular, já que CDI e Selic mudam com o tempo.

    Configurações

    Backup dos seus dados — tudo fica salvo apenas neste navegador

    Exportar backup

    Baixe um arquivo .json com todas as suas contas, receitas, dívidas e investimentos. Guarde em um lugar seguro ou use para levar seus dados para outro computador.

    Importar backup

    Selecione um arquivo .json exportado anteriormente. Isso substitui os dados atuais deste navegador.

    Limpar tudo

    Remove permanentemente todas as contas, dívidas e investimentos cadastrados neste navegador. Não pode ser desfeito — exporte um backup antes.

    Sobre

    Aplicação 100% local: nenhum dado sai do seu navegador, não há servidor nem conta para criar. Os dados ficam salvos no localStorage deste navegador/dispositivo — faça backups regulares.
